## Run locally

This is a static website built with HTML, CSS, and vanilla JavaScript; there are no dependencies or build steps.

1. Clone this repository.
2. Open `index.html` in a browser.

## Deploy with Vercel

Import this repository into Vercel with the **Other** framework preset. Use the repository root (`./`) as the project root and leave the build command empty.
